## 💡 About

A single-page store built with plain HTML, CSS and JavaScript — no frameworks and no build step.
It loads instantly, works great on phones and can be hosted anywhere for free.

> **Demo project.** The checkout is a front-end demo: orders are not sent anywhere yet.

## ✨ Features

- Catalog with search, filters and sorting
- Product pages with photos and size selection
- Favorites and a cart
- Checkout form with delivery or pickup
- Currency switcher
- Light and dark themes
- Mobile navigation with a bottom tab bar

## 🛠️ Tech stack

`HTML5` · `CSS3` · `Vanilla JavaScript` · `Responsive design` · `GitHub Pages`

## 🚀 Run locally

Download the repository and open `index.html` in a browser.
Product photos (`IMG_1749.JPG`–`IMG_1760.JPG`) must be next to `index.html`.
